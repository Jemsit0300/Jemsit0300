I build multilingual, data-driven REST APIs with **Django** and **Django REST Framework**, and take them all the way to production with **PostgreSQL**, **Nginx**, and **Gunicorn** — owning each project end to end, from data modeling to deployment. Comfortable working in **Ubuntu/Linux** environments, containerizing services with **Docker**, and administering servers over **SSH**.
